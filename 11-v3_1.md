# DD API V3.1 (Optioneel)

V3.1 is een optionele uitbreiding op DD API V3 en bevat een drietal specificaties, allen optioneel:

- [Pub/Sub](#pubsub-extensie) (publish/subscribe) op wijzigingen in observaties data. **PubSub** is **niet** READ-ONLY.
- [Zoekprofielen](#zoekprofielen-extensie) voor vooraf opgestelde selecties (`$filter` en `$select`) van observaties.
- [Resultaatprofiel](#resultaatprofiel-v3-1-extensie) voor het uniformeren van de responses.

Deze extensies zijn beschikbaar via de standaard v3-endpoints (onder /v3/). 
Hiermee blijven alle onderdelen van de Digitale Delta API V3 familie binnen dezelfde basis-URL bereikbaar.
